# Kanagawa for Obsidian

A community port of [kanagawa.nvim](https://github.com/rebelot/kanagawa.nvim) for Obsidian. All three variants — Wave (dark), Dragon (dark alt), Lotus (light).

## Variants

| Variant | Description |
|---------|-------------|
| **Wave** (default dark) | Deep ocean tones, warm dark |
| **Dragon** | Late-night muted, warm brown-black |
| **Lotus** | Warm parchment-like light mode |

Switch between Wave and Dragon in dark mode via the [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) plugin.

## Installation

1. Copy the `obsidian/` directory into `{vault}/.obsidian/themes/Kanagawa/`
2. In Obsidian: Settings → Appearance → Themes → select **Kanagawa**
3. (Optional) Install Style Settings to switch between Wave and Dragon

## Colors

All 104 palette colors from kanagawa.nvim are available as CSS custom properties (`--sumiInk3`, `--fujiWhite`, etc.).
